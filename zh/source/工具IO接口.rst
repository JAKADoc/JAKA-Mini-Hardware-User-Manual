工具端输入输出接口简称TIO（Tool Input and Output），在机器人末端法兰侧面，包括两个数字量输入，两个数字量输出与两个模拟量输入，同时可以复用两路RS485信号，其接口定义请参考 :ref:`连接工具端接口定义` 。

TIO线束有防呆设计，将TIO连接器突起与机器人末端法兰侧TIO连接器凹槽对齐后，插入线束即可，TIO位置如下图。

.. _工具端接线说明:

工具端接线说明
================

.. _数字输入:

数字输入
--------

TIO支持2路用户DI数字输入接口，NPN、PNP型兼容，可在App中进行配置，具体操作见 |软件| 软件用户手册。

**干接点型输入** 

当将DI输入配置成NPN型时：

干接点型输入（即开关型输入）一端连接TIO中GND（灰色线），另一端连接DI数字输入（蓝色或绿色线）。

.. figure:: ../../images/07_运输及调试/NPN型干接点输入接线.*
   :width: 9.67cm
   :align: center

   NPN型干接点输入接线

当将DI输入配置成PNP型时：

干接点型输入（即开关型输入）一端连接TIO中24V（红色线），另一端连接DI数字输入（蓝色或绿色线）。

.. figure:: ../../images/07_运输及调试/PNP型干接点输入接线.*
   :width: 9.72cm
   :align: center

   PNP型干接点输入接线

**连接NPN/PNP型设备**

连接NPN/PNP型数字量输入设备时，接线方式：V+连接TIO中的24V（红色线），0V连接TIO中的GND（灰色线），信号线连接TIO中的数字输入（蓝色或绿色线）。

.. figure:: ../../images/07_运输及调试/连接外部NPN设备接线.*
   :width: 8.55cm
   :align: center

   数字输出接口接线

| A 外部负载或输入设备
| B TIO V3
| C 主电路

.. _数字输出:

数字输出
--------

数字输出接口为NPN/PNP型输出时，采用开漏输出，最高支持连续1A电流能力输出。接线方式：外部输入端口连接TIO中的数字输出（黄色或粉色线），外部V+连接TIO中的24V（红色线），外部0V连接TIO中的GND（灰色线）。

.. figure:: ../../images/07_运输及调试/连接外部NPN设备接线_2.*
   :width: 8.58cm
   :align: center

   连接外部NPN设备接线

| A 外部 RS485 设备
| B TIO V3
| C 主电路

.. _RS485:

RS485
-----

使用RS485功能时，接线方式：外部RS485+接TIO中的RS485+（黄色或者棕色线），外部RS485-接TIO中的RS485-（粉色或者白色线），外部V+连接TIO中的24V（红色线），外部0V连接TIO中的GND（灰色线）。

.. figure:: ../../images/07_运输及调试/RS485接线.*
   :width: 7.6cm
   :align: center

   RS485接线

| A 外部模拟信号源或传感器
| B TIO V3
| C 主电路

.. _模拟输入:

模拟输入
--------

TIO支持2路模拟电压输入接口，其电压输入范围为0~10V。接线方式：外部模拟电压正端接入TIO中的AIN1/AIN2（白色或棕色线），负端在TIO板内部电路已经接地，外部V+连接TIO中的24V（红色线），外部0V连接TIO中的GND（灰色线）。

| B TIO V3
